# Instinct waitlist

Single-page site for the Instinct waitlist.

## Open the site

**Recommended** (local server — needed for reliable image loading):

```powershell
cd C:\Users\maany\Desktop\instinct
npx --yes serve -l 8080
```

Then open http://localhost:8080/

Or double-click `open-site.bat`.

You can also open `index.html` directly in the browser; guy photos in `photos/` should still load.
